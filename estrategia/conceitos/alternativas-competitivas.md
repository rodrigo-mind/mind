# Alternativas competitivas

## Definição

É o que os clientes ideais usariam ou fariam se o seu produto não existisse. Não precisa ser um produto concorrente: pode ser contratar um estagiário, usar uma planilha, seguir um processo manual ou simplesmente conviver com o problema sem fazer nada.

## Por que importa

- É a régua com que o cliente decide o que é "melhor". Dizer que seu produto é mais fácil que o de outras startups não vale nada se o cliente compara com uma planilha.
- Os recursos e o valor do produto só são únicos ou interessantes quando comparados a uma alternativa na cabeça do cliente.
- Perguntar apenas qual problema o cliente quer resolver não revela essas categorias: no exemplo do livro, usuários descreviam o problema como "rodar consultas rápidas", mas, sem o produto, apontavam ferramentas de inteligência de negócios e armazéns de dados, não outros bancos de dados.
- O cliente costuma saber muito menos que você sobre o universo de soluções. Um concorrente que você teme pode não existir para ele.

## Como se relaciona

É o primeiro componente do posicionamento e a base dos atributos únicos, que só são únicos em comparação com ela. O passo a passo está no framework listar alternativas competitivas.
