# Canibalização de palavras-chave

## Definição
Acontece quando a arquitetura do site faz várias páginas, às vezes dezenas, mirarem o mesmo termo nos títulos (title) e nos cabeçalhos. Em geral é involuntária. O buscador não entende isso como "o site é mais relevante para o termo"; ele precisa escolher uma das versões, e o resto compete entre si.

## Por que importa
Quatro perdas, segundo o livro:
- **Texto âncora interno** dividido entre páginas, em vez de reforçar um único destino.
- **Links externos** repartidos entre páginas parecidas, em vez de somados em uma.
- **Qualidade do conteúdo**: depois de três ou quatro páginas sobre o mesmo assunto, o texto se repete e perde valor; é melhor uma página forte que atraia links.
- **Conversão**: se uma página converte melhor, as outras são versões piores disputando o mesmo tráfego. Para comparar, o livro sugere teste A/B ou multivariado.

Como corrigir, segundo o livro: em vez de várias páginas para o mesmo termo, faça cada página mirar uma variação com valor próprio, todas apontando para uma página canônica do termo principal. Se o problema já existe, escolha a melhor página, redirecione as demais para ela com 301 e, se isso não for viável, use a tag canônica (canonical).

Outra forma de evitar a canibalização, segundo o capítulo 6: mapeie os termos em um fluxograma ou planilha e, quando uma página mirar uma frase mais longa que contém o termo-alvo de outra (por exemplo, "empréstimos de juro baixo" e "empréstimos"), linke de volta para a página principal com o texto âncora do termo mais curto, no corpo do texto ou na trilha de navegação.
