# JavaScript-The-Definitive-Guide-7th-Edition-(David-Flanagan) (pdf)

## Resumo

*JavaScript: The Definitive Guide*, sétima edição, de David Flanagan (O'Reilly, maio de 2020, 707 páginas, em inglês). Cobre a linguagem JavaScript de forma completa e as principais APIs de navegador e de Node, para quem já programa e quer dominar a linguagem. São 17 capítulos: introdução, estrutura léxica, tipos e variáveis, expressões, instruções, objetos, arrays, funções, classes, módulos, biblioteca padrão, iteradores e geradores, JavaScript assíncrono, metaprogramação, **JavaScript em navegadores** (capítulo 15, a partir da página 409), JavaScript no servidor com Node e ferramentas e extensões. O prefácio avisa que esta edição não traz mais a seção de referência e manda consultar o MDN e a documentação do Node.

Leitura parcial: li a capa, os créditos, o sumário e o prefácio (páginas iniciais até cerca da página 22 de 707). O texto inteiro foi verificado por busca e não há trecho dirigido ao Claude. O arquivo não tem JavaScript embutido.
